NoteGen Web Clipper 支持 Chrome、Microsoft Edge 和 Firefox，并通过本机回环地址连接正在运行的桌面端 NoteGen。移动端和 Safari 当前不支持。

## 安装并连接

1. 在桌面端打开“设置 → 记录设置 → 网页剪藏”。
2. 启用网页剪藏服务。
3. 点击安装按钮，或打开[网页剪藏下载页](/cn/web-clipper/download)。
4. 安装对应浏览器扩展，并保持 NoteGen 在后台运行。
5. 打开扩展弹窗，确认连接状态正常。

扩展默认连接 `127.0.0.1:37421`，只允许本机浏览器访问。连接失败时先确认 NoteGen 中的开关已启用，再重启扩展或浏览器。

## 保存选区和图片

在网页中选择文字后，旁边会显示快捷保存按钮。点击后，文字会保存为文本记录。选中图片时，每张图片会下载到 NoteGen，并作为独立图片记录处理；是否生成识别结果取决于图像识别设置。

不需要快捷按钮时，可以在扩展选项中关闭选区助手。关闭后扩展会注销对应内容脚本。

## 保存当前页面

打开扩展弹窗并保存当前页，页面 URL 会进入 NoteGen 的链接记录流程。NoteGen 会抓取标题、摘要和可用网页图片；网站登录、反爬策略或动态渲染可能限制抓取结果。

## 离线队列与限制

NoteGen 暂时不可用时，扩展会保留未发送剪藏并在重新连接后继续发送。队列最多保存 100 条或 50 MiB；单条 Markdown 内容上限为 2 MiB。达到限制后应先启动 NoteGen 并等待队列清空。

## 隐私

- 扩展没有账户、分析统计、Cookie 收集或云端中转服务。
- 只有点击保存时才读取选区；保存当前页时才读取当前标签页 URL。
- 剪藏只发送到本机 NoteGen；后续是否上传取决于你配置的识别模型、图床和同步服务。
- 扩展需要访问 HTTP/HTTPS 页面，才能在网页中显示选区保存按钮。

## 常见问题

- **显示未连接**：启动桌面端 NoteGen，启用网页剪藏，并检查安全软件是否拦截本机端口。
- **选区没有按钮**：刷新页面，确认选区助手已启用；浏览器内部页面和扩展商店页面通常禁止内容脚本。
- **图片没有识别文字**：检查 OCR/VLM 设置和模型状态。
- **网页内容不完整**：先保存为链接记录，再手动补充受登录或动态加载限制的内容。
