本页说明 NoteGen 客户端操作。开始前应由管理员完成[自托管部署](/cn/docs/self-hosted)，确认 HTTPS、就绪检查、数据库和对象存储备份正常。自托管同步当前属于实验性功能。

<NoteGenDocPreview kind="settings" section="sync" lang="cn" label="包含自托管入口的同步设置" />

## 准备

1. 在现有设备导出本地 ZIP，并备份 Markdown 工作区。
2. 向管理员确认服务器 URL、账户方式和兼容的客户端版本。
3. 在“高级设置”启用开发者模式，使自托管平台出现在同步设置中。
4. 不要让其他同步引擎同时写入准备绑定的工作区。

## 登录实例

打开“设置 → 同步配置 → NoteGen 自托管”，确认实验性功能提示后填写服务器 URL。优先使用浏览器授权；实例允许时也可以用登录名、密码和可选 TOTP 登录。

NoteGen 不会把已经使用 HTTPS 的地址自动降级为 HTTP。若局域网测试必须使用 HTTP，客户端会显示不安全警告；不要通过公网使用明文连接。

## 绑定资料库

连接后，NoteGen 会为当前工作区准备默认资料库。也可以：

- 新建资料库并为它创建独立本地目录；
- 将当前工作区切换到已有资料库；
- 查看资料库是只读还是可写；
- 在不同资料库之间切换本地工作区。

绑定前核对当前工作区路径和资料库名称。选择远程资料库可能切换本地工作区，不等于把原目录直接重命名。

## 成员与邀请

有权限的成员可以按登录名邀请账户，并选择 Viewer、Editor 或 Manager 角色，再细分查看历史、恢复、邀请、管理成员、重命名或删除资料库等能力。邀请可以由对方账户列表接受，也可以复制邀请链接。

只授予完成协作所需的最低权限。移除成员不会自动撤销对方已经导出的本地副本。

## 个人数据和冲突

工作区文件与记录、标签、聊天、画布、设置等个人数据可以分别控制同步范围。首次连接应明确上传本机还是采用远端状态。

如果一个本地工作区被错误绑定到多个资料库，客户端会显示冲突。选择正确目标后可以转移到资料库，或保留本地副本。处理前先关闭自动同步并导出 ZIP，不要连续尝试覆盖。

## 断开与恢复

断开连接不会自动删除本地工作区。准备重新连接前保留服务器地址、账户、恢复信息和本地备份。无法登录时先检查服务器就绪、证书、设备时间和浏览器授权回调，再联系实例管理员；不要通过公开 Issue 发送密码、TOTP、恢复密钥或邀请链接。
