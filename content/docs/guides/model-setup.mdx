NoteGen 可以直接使用内置模型，也可以连接你自己的 OpenAI 兼容服务、Ollama 或 LM Studio。模型平台与具体功能的模型选择是分开的。

<NoteGenDocPreview kind="settings" section="ai" lang="cn" label="包含模拟平台与模型数据的模型设置" />

## 添加服务

1. 打开“设置 → 模型服务”。
2. 选择内置平台模板或新建自定义平台。
3. 填写名称、Base URL 和 API Key。
4. 添加模型名称并选择正确类型，例如 `chat`、`embedding`、`rerank`、`stt` 或 `tts`。
5. 运行连接测试并保存。

Base URL 通常填写到版本路径，例如 `https://api.openai.com/v1`，不要附加 `/chat/completions`。Ollama 默认可使用 `http://localhost:11434/v1`，LM Studio 常用 `http://localhost:1234/v1`，但本地服务必须已启动。

## 选择功能模型

添加模型后，前往对应设置选择它：

| 场景 | 设置位置 | 常用类型 |
| --- | --- | --- |
| Chat、Agent、整理 | 模型选择或默认模型 | `chat` |
| 图片理解 | 图像识别 | 支持视觉的 `chat` |
| 知识库索引 | 知识库 | `embedding` |
| 检索重排 | 知识库 | `rerank` |
| 录音转写 | 语音设置 | `stt` |
| 朗读 | 朗读设置 | `tts` |

## 代理与兼容参数

供应商可以继承全局代理、强制直连或使用自定义代理。旧兼容接口如果不接受 `max_completion_tokens`，可改用 `max_tokens`。上下文窗口、温度和最大输出长度不确定时先保留默认值。

## 安全与排错

- API Key 会保存在本机配置；只有启用设置同步时才可能按同步策略上传。
- 不要在 Issue、截图、诊断日志或共享配置中公开密钥。
- `401/403` 通常表示 Key、权限或账户问题；`404` 常见于 Base URL 或模型名错误；超时先检查网络和代理。
- 本地模型在手机上不能通过 `localhost` 访问电脑，需要使用局域网地址并确认防火墙规则。

完整字段说明参见[模型配置](/cn/docs/settings/model-config)与[模型选择和回退](/cn/docs/settings/default-model)。
