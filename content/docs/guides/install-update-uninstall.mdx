## 安装

| 平台 | 安装方式 | 注意事项 |
| --- | --- | --- |
| Windows | x64 安装程序 | 首次运行可能触发系统信誉或安全软件提示，请核对发布来源 |
| macOS | Apple Silicon 或 Intel DMG | 选择与芯片匹配的包，并将应用拖入“应用程序” |
| Linux | AppImage、Deb 或 RPM | AppImage 可能需要添加执行权限，Deb/RPM 应使用系统包管理器安装 |
| Android | ARM64 APK | 需要允许当前浏览器或文件管理器安装未知来源应用 |
| iOS | TestFlight | 测试名额和构建有效期以下载页显示为准 |

首次启动后选择 Markdown 工作区，并按系统提示授予文件、照片、麦克风或通知权限。只在使用对应功能时授予权限即可。

## 更新

桌面端会检查新版本；也可以从下载页手动安装新版。更新前建议：

1. 等待同步完成；
2. 导出本地 ZIP；
3. 记录当前版本和重要模型/同步配置；
4. 关闭 NoteGen 后再运行安装包。

移动端升级通常会保留应用数据，但测试版和系统清理策略可能不同，重要内容仍应有独立备份。

## 降级

新版本可能包含数据库或配置迁移。直接安装旧版并不能保证读取新版本数据。确需降级时，先备份当前状态，再安装旧版，并优先恢复由该旧版或兼容版本创建的 ZIP。不要让新旧版本同时对同一远程数据自动同步。

## 卸载与清理

Markdown 工作区是普通文件夹，卸载应用通常不会主动删除它；应用数据库、配置、缓存和本地密钥位于系统应用数据目录，平台卸载行为可能不同。

如果希望保留数据，先导出 ZIP 并复制工作区。如果希望彻底删除：

1. 在“高级与开发者设置”中分别确认清理数据和清理文件的范围；
2. 撤销 Git、S3、WebDAV、图床、模型和 MCP Token；
3. 删除不再需要的远程仓库、对象或自托管账户数据；
4. 卸载应用后检查工作区和系统应用数据目录。

清理操作不可撤销，执行前必须验证备份。
