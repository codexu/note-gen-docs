这条流程适合第一次使用 NoteGen，也适合会议纪要、研究摘录、周报和灵感整理。

<NoteGenDocPreview kind="organize-notes" lang="cn" label="使用模拟记录的 AI 整理界面" />

## 1. 收集素材

打开“记录”，添加几条文字记录，也可以混合图片、链接、文件、录音或待办。为同一主题添加相同标签，之后更容易筛选。

记录阶段只保存事实和想法，不必提前决定文章结构。图片识别、录音转写和链接抓取可能需要网络或已配置模型。

## 2. 选择范围

使用搜索、标签、时间和类型筛选缩小范围，然后进入多选模式。检查选中的素材是否包含私人信息、重复内容或无关文件。

## 3. 整理为 Markdown

点击“整理”，选择输出文件夹、文件名和整理模板。首次使用可以选择默认模板；会议纪要、研究总结等固定场景适合在[整理模板](/cn/docs/settings/organize-template)中保存专用提示词。

提交后，NoteGen 会把所选记录连同模板要求发送给整理模型，并生成 Markdown 文件。记录不会因为整理而被删除。

## 4. 审阅与继续写作

在编辑器中检查标题层级、事实、链接、待办和图片位置。AI 生成内容可能遗漏或误解素材，重要结论应与原记录核对。

你可以继续：

- 手动编辑或拖动章节；
- 选中文字进行润色、精简、扩写或翻译；
- 将原记录或其他文件拖入编辑器；
- 让 Agent 提出修改，并在 Diff 中逐项确认。

## 5. 保存与同步

Markdown 会自动保存到当前工作区。需要跨设备时，再配置[多设备同步](/cn/docs/guides/multi-device-sync)；在首次同步前先导出本地 ZIP 备份。
