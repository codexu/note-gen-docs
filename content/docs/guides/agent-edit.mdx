Agent 可以调用 NoteGen 内置工具读取和修改文件、记录、标签与记忆，也可以使用你启用的 MCP 和 Skills。它比普通 Chat 权限更高，因此应先限定范围再执行。

## 开始前

1. 打开目标笔记，或在消息中明确文件路径。
2. 只启用任务需要的知识库、MCP 和 Skills。
3. 对重要文件先创建副本或本地 ZIP 备份。
4. 在提示中写清目标、不允许修改的内容和验收条件。

例如：

> 重组当前笔记的二级标题，保留原始事实和链接，不新增未经来源支持的结论。修改完成后列出调整摘要。

## 审核过程

- 读取、搜索和生成草稿通常不会直接改文件。
- 写入、移动或删除操作会按当前权限策略请求确认。
- 编辑器变更以 Diff 展示；检查删除内容、链接、代码块和图片路径后再接受。
- 涉及多个文件时逐项检查，不要仅根据总结一次性批准。

## 降低风险

- 将任务拆成“分析 → 提案 → 修改”三个阶段。
- 要求 Agent 先列出计划修改的文件。
- 不要同时开放与任务无关的文件系统或远程 MCP。
- 对事实性内容要求引用原笔记或网络来源。
- Agent 长任务进入队列后，可继续输入补充要求；如果方向错误应立即停止。

如果结果不符合预期，拒绝 Diff 或使用编辑器撤销；已完成的跨文件操作应从备份、同步历史或 Git 历史恢复。能力边界参见[AI 对话与 Agent](/cn/docs/preview/chat)。
