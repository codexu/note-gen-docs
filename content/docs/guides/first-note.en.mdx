This workflow is useful for a first NoteGen session and for meeting notes, research excerpts, weekly reports, or idea collection.

<NoteGenDocPreview kind="organize-notes" lang="en" label="AI organization interface with simulated records" />

## 1. Capture material

Open Records and add a few text records. You can mix in images, links, files, recordings, and todos. Give related material the same tag so it is easier to filter later.

Capture facts and ideas without deciding the final structure. Image recognition, transcription, and link capture may require a network connection or configured model.

## 2. Select a range

Use search, tags, time, and type filters, then enter multi-select mode. Check the selection for private, duplicate, or irrelevant material.

## 3. Organize into Markdown

Select Organize, then choose the destination folder, file name, and template. The default template is enough for a first run. Save dedicated prompts for recurring meeting, research, or reporting workflows under [Organize Template](/en/docs/settings/organize-template).

NoteGen sends the selected records and template instructions to the organization model and creates a Markdown file. Organizing does not delete the source records.

## 4. Review and continue writing

Check headings, facts, links, todos, and image placement in the editor. Generated content can omit or misunderstand source material, so verify important conclusions against the original records.

You can then:

- edit manually or reorder sections;
- polish, shorten, expand, or translate a selection;
- drag original records or other files into the editor;
- ask Agent to propose changes and approve each Diff.

## 5. Save and sync

Markdown saves automatically in the current workspace. Configure [multi-device sync](/en/docs/guides/multi-device-sync) when needed, and export a local ZIP before the first sync.
