导入会在当前工作区创建文件。开始前确认目标文件夹，并为已有工作区创建 ZIP 备份，避免同名文件或资源路径覆盖。

## 导入 Markdown

在文件管理器的更多菜单中选择“导入 Markdown”，可批量复制 Markdown 及其可识别资源到当前工作区。导入后检查图片相对路径、内部链接和同名文件。

## 导入 Notion ZIP

1. 在 Notion 中导出工作区或页面，选择 Markdown/CSV 格式并包含子页面。
2. 保留原始 ZIP，不要手动改变包内层级。
3. 在 NoteGen 文件管理器选择“导入 Notion”。
4. 选择 ZIP 和目标目录，等待导入完成。
5. 抽查嵌套页面、图片、附件和文件名。

数据库视图、Notion 专有块、权限和评论不能保证一对一转换。原始导出 ZIP 应保留到迁移验收完成。

## 将办公文档转换为 Markdown

“文档转 Markdown”支持：

- Word：DOC、DOCX、DOCM；
- Excel：XLS、XLSX、XLSM、XLSB；
- PowerPoint：PPT、PPTX、PPTM、PPS、PPSX、PPSM、POT；
- OpenDocument：ODT、ODS、ODP；
- RTF、EPUB、CSV 和 PDF。

转换会尽量保留正文和可表达的结构，但复杂排版、批注、动画、公式、合并单元格和嵌入对象可能简化。扫描 PDF 没有文本层，应先通过 OCR 生成文字。

## 切换或迁移工作区

切换工作区只改变 NoteGen 当前打开的目录，不会移动旧文件。需要迁移时：

1. 导出完整 ZIP 备份并关闭自动同步。
2. 使用系统文件管理器复制旧工作区到新位置，或使用平台提供的云盘迁移操作。
3. 在 NoteGen 中选择新目录并重启应用。
4. 检查 Markdown、图片、音频和附件。
5. 重建知识库索引，再重新配置或验证同步仓库映射。

## 验证与回滚

迁移完成后统计关键文件夹和文件数量，抽查图片、链接、中文文件名和较大文档。确认无误前不要删除旧工作区。

如果导入失败或结果不完整，停止在目标工作区继续编辑，保留错误信息，切回旧工作区或从 ZIP 恢复，然后使用较小批次重新导入。
