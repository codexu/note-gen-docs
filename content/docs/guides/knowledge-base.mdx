知识库适合跨多篇 Markdown 查找相关片段。它不会训练模型，而是在提问时检索工作区内容并加入当前对话上下文。

## 准备模型

先在模型服务中添加 `embedding` 模型。可选的 `rerank` 模型用于对初步结果重新排序；没有它也可以使用知识库。

## 建立索引

1. 打开“设置 → 知识库”。
2. 选择嵌入模型和可选重排模型。
3. 配置分块大小、重叠和返回数量；不确定时保留默认值。
4. 为整个工作区或指定文件夹建立索引。
5. 等待索引完成，并处理列表中显示的失败文件。

索引主要针对 Markdown。修改文件后，开启自动计算可以更新对应索引；批量移动、外部编辑或切换工作区后建议检查索引状态。

## 在对话中使用

打开 Chat 或 Agent，在工具栏启用知识库后再提问。问题应包含明确主题、时间或文档范围，例如“根据项目周报总结七月的三个主要风险”。要求回答列出引用文件，便于回到原文核对。

## 维护与隐私

- 切换嵌入模型后应重建索引，因为不同模型的向量不可直接混用。
- 删除或大规模移动文件后重建索引，避免旧路径残留。
- 索引保存在本机，但在线嵌入和重排模型会收到被处理的文本片段。
- 检索结果受分块和模型能力影响，不应把“未检索到”理解为文件中不存在。

参数说明参见[知识库设置](/cn/docs/settings/rag)。
