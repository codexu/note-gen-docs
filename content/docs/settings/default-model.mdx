NoteGen 将模型平台与功能场景分开管理。先在[模型配置](/cn/docs/settings/model-config)中添加平台及模型，再在对话或对应功能的设置页中选择模型。模型服务页也会展示无需额外配置即可使用的默认免费模型。

## 模型回退

对话输入框中当前选择的模型用于 Chat 和 Agent。编辑器、记录等场景未单独选择模型时通常跟随当前主要模型；明确选择“不使用模型”时则关闭对应 AI 能力。

## 配置位置

| 场景 | 设置位置 | 建议 |
| --- | --- | --- |
| Chat / Agent | 对话输入框的模型选择器 | 使用综合能力和工具调用较好的聊天模型 |
| 长对话压缩 | 自动跟随当前对话模型 | 压缩由上下文用量自动或手动触发 |
| 编辑器补全 | 编辑器设置 | 使用低延迟聊天模型，未选择时跟随主要模型 |
| 记录描述 | 记录设置 | 使用轻量聊天模型，未选择时跟随主要模型 |
| 知识库嵌入/重排 | 知识库 | 必须匹配 embedding / rerank 类型 |
| 图片理解 | 图像识别 | 选择支持视觉输入的模型 |
| 语音转文字 | 音频设置 | 选择 stt 类型模型 |
| 文本朗读 | 语音设置 | 选择 tts 类型模型，或使用系统语音 |

更换嵌入模型后，建议重新计算知识库向量，避免不同模型生成的向量混用。
