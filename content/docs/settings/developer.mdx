这些选项位于“设置 → 常规设置 → 高级设置”。开发者模式只在当前设备生效，开启后会显示自托管同步和开发者诊断等入口。

## 网络与诊断

- 网络代理用于处理无法直连模型或同步服务的情况，修改后建议重启应用。
- 开发者工具可通过设置按钮、`F12`、`Cmd/Ctrl+Shift+I` 或右键检查元素打开。
- 性能信息会在编辑器中显示文档大小、工作模式和渲染耗时。
- 诊断日志支持先生成脱敏预览，再复制或导出 JSON。自动脱敏无法覆盖全部业务文本，提交前仍需人工检查。

## 数据与配置

- 导出配置可以保留当前设置；导入 JSON 会覆盖现有配置，并在重启后生效。
- “清理数据”会永久删除系统配置、数据库和全部记录。
- “清理文件”会永久删除本地图片、文章和临时文件。

执行清理或导入前，请先在“备份与恢复”中导出完整备份，并确认备份文件可以正常保存。
