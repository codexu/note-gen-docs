## 选择模型

在对话输入框的模型选择器中选择 Chat 和 Agent 当前使用的模型。模型平台、API Key 和模型列表统一在“设置 → 模型服务”中管理；记录、编辑器、知识库等功能的场景模型仍在各自的设置页中选择。

## 对话工具栏

前往“设置 → 常规设置 → 工具设置”，调整桌面端和移动端对话工具栏按钮的显示、顺序和可见性。可配置模型、提示词、回复语言、关联标签、关联文件、MCP、知识库、剪贴板监听、新对话、清除上下文和清空对话。

“清除上下文”保留界面中的历史消息，但后续请求不再携带此前内容；“清空对话”会删除当前会话历史。

## 上下文压缩

接近模型上下文上限时，NoteGen 会将较早的对话压缩为续接摘要，并保留最近消息继续对话。上下文用量入口也可以手动触发压缩。

压缩会保留对话主线，但可能省略措辞和次要细节。需要精确引用旧消息时，请回看原始内容、清理无关上下文，或开始新对话。
