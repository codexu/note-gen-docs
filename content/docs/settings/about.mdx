## 版本与更新

“关于”显示当前 NoteGen 版本和可用更新。桌面端可以在这里检查、下载并安装新版；如果应用内更新失败，前往[下载页面](/cn/download)或 GitHub Releases 手动安装。

更新前等待同步完成并导出本地 ZIP。安装、降级与数据保留说明参见[安装、更新与卸载](/cn/docs/guides/install-update-uninstall)。

## 项目入口

页面提供官网、GitHub、Issues 和 Discussions。提交问题时先搜索重复 Issue，并附上版本、系统、复现步骤和脱敏诊断信息。

## 社区与支持

社区区域提供交流入口；赞助与商业合作入口用于支持项目或联系团队。社区成员不是官方客服，不要在公开频道发送 API Key、同步 Token、恢复密钥或私人笔记。
