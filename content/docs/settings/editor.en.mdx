## Editor model

Select the chat model used for inline AI completion. A fast and predictable model usually feels best. Configure the accept and cancel keys under Shortcuts.

## Layout

- **Content width:** choose narrow, standard, wide, or the full available area.
- **Line height:** choose compact, comfortable, or relaxed.

Layout changes display only and does not modify Markdown.

## Editor mode

- **Visual:** edit rendered Markdown structures directly.
- **Source:** edit raw Markdown, with optional line numbers and wrapping.

Both modes operate on the same file. Verify documents with custom syntax after switching for the first time.

## Outline and controls

- Choose whether the outline opens by default and whether it appears on the left or right.
- The outline supports navigation and drag-to-reorder sections.
- Show or hide Undo and Redo in the tab bar; shortcuts continue to work when hidden.
- Show or hide character, word, line, and editor-status statistics.

Split groups, separate windows, and the new-tab page are editor actions and do not change these defaults. See [Markdown editor](/en/docs/preview/writing) for the full workflow.
