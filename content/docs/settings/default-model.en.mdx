NoteGen separates model platforms from feature-specific model selection. First add platforms and models under [Model Configuration](/en/docs/settings/model-config), then choose a model in the conversation or the relevant feature settings. Model Services also lists included models that work without additional provider setup.

## Fallback behavior

The model selected beside the composer is used by the current Chat or Agent conversation. Editor, capture, and other scenarios normally follow the primary model when no separate model is selected. Choosing No Model disables that AI capability.

## Where to configure models

| Scenario | Settings page | Recommendation |
| --- | --- | --- |
| Chat / Agent | Model selector beside the composer | Strong chat and tool-calling model |
| Conversation compaction | Follows the active conversation model | Triggered automatically or manually from context usage |
| Editor completion | Editor | Low-latency chat model; follows the primary model when unset |
| Record descriptions | Record | Small chat model; follows the primary model when unset |
| Knowledge-base embedding/rerank | Knowledge Base | Match the embedding/rerank type |
| Image understanding | Image Recognition | Vision-capable model |
| Speech to text | Audio | STT model |
| Read aloud | Audio | TTS model or system voice |

After changing the embedding model, rebuild knowledge-base vectors so vectors from different models are not mixed.
