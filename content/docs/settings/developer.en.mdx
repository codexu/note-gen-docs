These options are under Settings → General Settings → Advanced settings. Developer mode applies only to the current device and reveals self-hosted sync and developer diagnostics.

## Networking and diagnostics

- Use the network proxy when model or sync services cannot be reached directly. Restart NoteGen after changing it.
- Open developer tools from Settings, `F12`, `Cmd/Ctrl+Shift+I`, or the Inspect context-menu action.
- Performance information shows document size, editor mode, and render timing in the editor.
- Diagnostics can generate a redacted preview before you copy or export JSON. Automatic redaction cannot catch every piece of user content, so review it before sharing.

## Data and configuration

- Export the current configuration for reuse. Importing JSON overwrites existing settings and takes effect after restart.
- Clear Data permanently removes system settings, the database, and all captures.
- Clear Files permanently removes local images, notes, and temporary files.

Before importing or clearing anything, create a full export under Backup & Restore and confirm that the backup file was saved successfully.
