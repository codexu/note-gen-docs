## Display

- **Show grid:** display or hide the alignment grid.
- **Snap to grid:** align moved nodes to the current grid interval.
- **Show minimap:** display an overview in the corner of the canvas.
- **Grid style:** choose dots, lines, or no grid.
- **Grid gap:** adjust density from 8–48 px; it has no effect while the grid is hidden.
- **Default zoom:** set the initial zoom level when a canvas opens.

These options change display and interaction only. Snap to grid can change an element's final position after it is moved.

## Interaction

- **Wheel behavior:** on desktop, use the mouse wheel to zoom or pan.
- **After insertion:** keep the current insertion tool active or return to Select.

Mobile uses touch gestures and therefore does not show the desktop wheel preference.

## Canvas manager

- **Default view:** choose grid or list on desktop; mobile uses a narrow-screen layout.
- **Default sort:** sort by update time, creation time, or name.

These preferences apply when canvases and the manager are opened. They do not rearrange nodes in an existing canvas. See [Canvas](/en/docs/preview/canvas) for the full workflow.
