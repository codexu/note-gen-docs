## Select a model

Choose the model used by the current Chat or Agent conversation from the model selector beside the composer. Manage providers, API keys, and model lists under Settings → Model Services. Scenario models for capture, the editor, and the knowledge base remain on their respective settings pages.

## Chat toolbar

Open Settings → General Settings → Tool settings to change the order and visibility of desktop and mobile controls: model, prompt, response language, linked tag, linked files, MCP, knowledge base, clipboard monitor, new chat, clear context, and clear chat.

Clear Context keeps visible history but excludes earlier messages from future requests. Clear Chat deletes the current conversation history.

## Context compaction

When a conversation approaches the model's context limit, NoteGen compacts older turns into a continuation summary while retaining recent messages. You can also start compaction manually from the context-usage control.

Compaction preserves the main thread but may omit exact wording and minor details. Review the original messages, remove irrelevant context, or start a new conversation when precise historical wording matters.
