## Version and updates

About shows the installed NoteGen version and available updates. Desktop can check, download, and install a release here. If in-app update fails, use the [download page](/en/download) or GitHub Releases.

Wait for sync and export a local ZIP before updating. See [Install, update, and uninstall](/en/docs/guides/install-update-uninstall) for downgrade and data-retention guidance.

## Project links

The page links to the website, GitHub, Issues, and Discussions. Search for duplicates before reporting a problem and include the app version, OS, reproduction steps, and redacted diagnostics.

## Community and support

Community links provide discussion spaces. Donation and business links support the project or contact the team. Community members are not a private support channel; never post API keys, sync tokens, recovery keys, or private notes.
