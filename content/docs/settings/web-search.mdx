网络搜索为 Chat 和 Agent 提供当前网页信息。NoteGen 按“模型原生搜索 → 第三方搜索 API → 基础网页搜索”的顺序尝试可用能力，并在上一层关闭或不可用时回退。

## 模型原生搜索

启用后，支持联网搜索的模型可以使用供应商原生能力。还需要在对应模型配置中开启网络搜索；不支持该能力的模型会继续尝试下一层。

原生搜索的来源格式、搜索范围和计费由模型供应商决定。

## 第三方搜索 API

NoteGen 支持智谱 Web Search、Tavily、Brave Search 和 Exa。填写 API Key 后使用连接测试确认配置有效，并拖动服务调整尝试顺序。

“自动”模式按这里的顺序选择已配置且可用的服务。关闭第三方搜索不会删除已保存的 Key。

## 基础网页搜索

基础搜索不依赖单独的第三方搜索 Key，适合作为最后回退。它的结果质量、可访问站点和稳定性可能低于专用搜索 API，受网络环境和网站限制影响更明显。

## 在对话中使用

1. 打开 Chat 或 Agent。
2. 在对话工具栏启用网络搜索。
3. 提出需要当前信息的问题，并要求附带来源。
4. 打开来源链接核对关键事实、日期和上下文。

网络搜索与知识库作用不同：网络搜索读取公开网页，知识库检索自己的工作区内容。两者可以同时使用。

## 隐私与排错

- 搜索词会发送给实际处理请求的模型或搜索服务。
- API Key 保存在 NoteGen 配置中；分享配置或日志前先移除密钥。
- 测试失败时检查 Key、账户额度、服务地区限制、代理和系统时间。
- 有结果但模型没有引用时，确认当前模型支持工具调用，并在新对话中重试。
- 涉及医疗、法律、财务等重要决定时，应打开原始来源交叉核对。
