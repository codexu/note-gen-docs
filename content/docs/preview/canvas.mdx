画布适合表达仅靠线性文档不容易看清的关系。它与记录和 Markdown 写作并列为一级工作区，画布中的元素在保存后仍可继续编辑。

<NoteGenDocPreview kind="desktop-canvas" lang="cn" label="桌面端画布界面" />

## 创建画布

在左侧栏切换到“画布”，点击新建并选择空白画布或模板。内置模板包括流程图、思维导图、时间线、四象限、看板和 SWOT；模板只是起点，创建后可以自由修改。

画布列表支持网格与列表视图、按更新时间/创建时间/名称排序、重命名、复制、置顶、删除与回收站恢复。

## 添加和编辑内容

- 使用选择或抓手工具选择、移动和查看内容。
- 使用画笔、高亮笔与橡皮擦进行自由绘制。
- 插入文字、图片、分组和常用流程图形状。
- 用连接线表达节点关系，并编辑连线标签。
- 从记录列表拖入文本、图片、链接、文件或待办。
- 从文件管理器拖入 Markdown 笔记，让画布保留对原文件的引用。

选中元素后可以调整文字、颜色、边框、透明度、层级、尺寸和对齐。多个元素可以批量对齐、分布或组合为自定义组件，供当前画布重复使用。

## 图表与 AI

图表面板可以读取手动输入的数据，也可以选择工作区笔记作为资料。选择图表类型或交给模型自动判断后，NoteGen 会生成仍可编辑的柱状图、折线图、面积图、饼图等图表。

生成图表需要可用的聊天模型。发送给模型的内容包括你输入的数据和主动选择的笔记；处理敏感资料前请确认模型服务的隐私策略。

## 自动布局和视图

- 自动布局可按画布方向重新排列节点和连线。
- 小地图用于快速定位大型画布。
- 网格与吸附有助于保持节点对齐。
- 缩放、适应视图和框选适合浏览较大的结构。

## 导入与导出

画布可以导入 NoteGen 画布 JSON，以及 Mermaid 的 `flowchart`/`graph` 流程图语法。导出支持：

- PNG 或 SVG 图片；
- 作为图片记录保存回 NoteGen；
- 可再次导入的画布 JSON；
- Mermaid 流程图文件。

Mermaid 只覆盖可映射的流程图节点和连线，自由绘制、图片、图表、分组等元素不会完整保留。需要无损备份时请选择画布 JSON。

## 保存、同步与移动端

画布数据保存在 NoteGen 应用数据中，并生成缩略图用于列表展示。启用记录与配置同步后，画布会随结构化数据一同同步；发生失败时列表会显示待上传或失败状态。

移动端可以浏览和编辑画布，工具栏针对触控重新排列。桌面端更适合复杂连线、批量选择和大范围布局。

画布显示与操作偏好参见[画布设置](/cn/docs/settings/canvas)。
